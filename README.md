# 🚲 Bike Sales Analysis & Interactive Excel Dashboard

An interactive **Bike Sales Analysis Dashboard** created using Microsoft Excel to explore customer demographics, purchasing behavior, and factors influencing bike purchases.

This project was created as my **first hands-on Excel data analytics project**, with a focus on learning data cleaning, Pivot Tables, data visualization, and interactive dashboard creation.

---

## 📌 Project Overview

The objective of this project is to analyze a dataset of bike buyers and identify patterns in customer demographics and purchasing behavior.

The analysis transforms raw customer data into an interactive dashboard using:

* Data Cleaning
* Pivot Tables
* Charts & Graphs
* Slicers
* Filters
* Interactive Dashboard

The dashboard allows users to dynamically explore the data based on different customer characteristics.

---

## 📊 Dataset

The dataset contains customer demographic and purchasing information.

### Dataset Features

The dataset includes **1,026 customer records** and **13 columns**.

Some of the major attributes include:

* Gender
* Marital Status
* Age
* Income
* Number of Children
* Education
* Occupation
* Home Ownership
* Number of Cars
* Commute Distance
* Region
* Purchased Bike

### Target Variable

**Purchased Bike**

This indicates whether a customer purchased a bike.

## 🔄 Project Workflow

The project was completed through the following stages:

### 1. 📥 Data Collection

Started with the raw Bike Buyers dataset containing customer demographic and purchasing information.

### 2. 🧹 Data Cleaning

The raw dataset was prepared for analysis by checking and organizing the available data.

The cleaning process included:

* Reviewing the dataset structure
* Checking the data for inconsistencies
* Organizing fields for analysis
* Preparing the data for Pivot Tables and visualization

### 3. 📑 Working Sheet

A separate **Working Sheet** was created to perform the required data preparation and analysis before building the final dashboard.

### 4. 📊 Pivot Table Analysis

Pivot Tables were created to summarize the dataset and identify relationships between customer characteristics and bike purchases.

The Pivot Tables helped analyze factors such as:

* Age
* Gender
* Income
* Region
* Commute Distance
* Education
* Occupation
* Bike Purchase Status

### 5. 📈 Data Visualization

Charts and graphs were created from the analyzed data to make the results easier to understand.

These visualizations help identify patterns and differences between customers who purchased bikes and those who did not.

### 6. 🎛️ Interactive Filters & Slicers

Slicers were added to make the dashboard interactive.

Users can filter the dashboard based on different customer attributes and dynamically explore the results.

### 7. 📊 Interactive Dashboard

The final dashboard combines:

* Charts
* Graphs
* Pivot Table analysis
* Slicers
* Filters

into a single interactive Excel dashboard.
